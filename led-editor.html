ArduPlane Stratos · NTF_LS* LED segments

LED Segment Editor

Split a NeoPixel strip into up to 8 segments, INAV style: navigation lights, flight-mode colour, battery bar, strobe. The preview runs the same rules as the firmware. Export a .param file and load it in Mission Planner.

needs Stratos firmware with LED segments (not released yet)

Strip

LED 1 is the first LED after the data input. Drag across LEDs to place the highlighted segment. Where segments overlap, the higher-numbered one wins. Uncovered LEDs stay off.

Wiring

  • Use an output whose timer drives nothing else. Every output in a timer group shares one protocol, so a strip in a DShot motor group breaks.
  • SpeedyBee F405 WING Buzz: the LED pad is output 12 and has its timer to itself. The tone buzzer on S11 runs on a different timer, so melodies and the strip work together.
  • Also usable: speedybee F4 V3 output 9, AtomRC F405 NAVI output 9, Matek F405-TE output 12. Matek F405-Wing: not the LED pad (no DMA), but output 9 works if you give up outputs 7 and 8 (same timer). Not usable (no DMA on the pad, or the pad drives a buzzer or relay): CoreWing F405 Wing V2 / Mini V2, Kakute F4 Wing Buzz, AtomRC NAVI Buzz, Omnibus F4 Pro.
  • Power the strip from 5 V, not the flight controller's 5 V pin if you run more than a few LEDs at full brightness.

Limits

  • RAM depends only on NTF_LED_LEN: about 96 bytes per LED when the LED output has its timer to itself, 384 when it shares the timer. It is set at boot and never changes with the pattern.
  • CPU grows with the number of LEDs your segments cover, not with the effect. Avoid stacking several full-length segments on top of each other.
  • Bench check before flying: compare the PM log (NLon, MaxT, Load) with NTF_LS_ENABLE 0 and 1, and confirm EKF3 starts and a log is written when you arm.
  • NTF_LED_LEN needs a reboot. The segment parameters apply live.
  • Battery needs a capacity estimate (BATT_CAPACITY). Without one the segment shows its COLOR.
  • NTF_LS_ENABLE 0 brings back the stock single-colour status strip.
